Le point de départ de toutes les autres recettes : un espresso au **ratio 1:2**.

| Paramètre | Valeur |
| --- | --- |
| Portions | 1 |
| Café en grains | 18 g |
| Eau (en tasse) | 36 g |
| Température | 93 °C |
| Temps d'extraction | ~28 secondes |

## Matériel

- Moulin
- Machine à espresso

## Étapes

1. Moudre **18 g** de café en grains finement dans le moulin.
2. Extraire **36 g** d'eau à **93 °C** dans la machine à espresso, pendant environ **28 secondes**.
